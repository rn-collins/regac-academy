# REGAC Regulatory Academy | Source-Governed Learning Lab

An interactive regulatory literacy academy for learning how to classify authority, track jurisdiction and currentness, compare regimes, and document escalation.

**Live:** https://regac-academy.vercel.app

## Repository contents

`academy.css`, `academy.js`, `index.html`, `privacy.html`, `robots.txt`, `sitemap.xml`, `terms.html`, `vercel.json`

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
